# mk-main-guide

本仓库用于归档和发布多个独立 HTML 页面。这些页面以静态形式存放，不依赖后端服务，可直接通过浏览器访问。

## 项目简介

mk-main-guide 是一个静态页面集合仓库。各页面彼此独立，无关联依赖，适合作为参考、演示或历史存档使用。仓库本身不针对任何特定网站或域名，仅提供页面内容的存储与版本管理。

## 目录说明

```
.
├── index.html          # 仓库主页，列出所有归档页面入口
├── pages/              # 存放各独立 HTML 页面
│   ├── page-example-1.html
│   ├── page-example-2.html
│   └── ...
├── assets/             # 公共资源文件（样式、脚本、图片等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md           # 本文件
```

- `pages/`：每个 HTML 文件为一个独立页面，建议按功能或阶段命名。
- `assets/`：存放页面共用的样式、脚本与图片资源，避免重复引入。

## 页面归档说明

- 所有页面均为静态 HTML，不包含后端逻辑。
- 页面之间无跨文件依赖，可单独打开使用。
- 归档内容可能来自不同时期或用途，仅供存档与查阅。
- 不保证所有页面持续更新或兼容最新浏览器版本。
